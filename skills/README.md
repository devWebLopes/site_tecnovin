## Regras de Uso

1. Cada skill define competências, ferramentas e convenções específicas.
2. Agentes devem consultar suas skills relevantes antes de gerar código ou conteúdo.
3. Skills de domínio devem ser seguidas rigorosamente para manter a consistência editorial e visual do projeto.
4. Quando uma task cruza múltiplas skills, o agente deve integrar as orientações de todas as skills aplicáveis.
5. Dados factuais sobre a empresa Tecnovin devem ser fundamentados na base de conhecimento `docs/dossie_Tecnovin/`.
